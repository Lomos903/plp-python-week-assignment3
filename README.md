Grade Reporter & Bug Hunt
Files
grade_reporter.py — Uses loops and conditions to calculate learner grades, pass and fail counts, and the average score.
bug_hunt.py — Fixes three bugs in a while-loop program that calculates the sum of numbers 1 to 5.
Bug Hunt Reflection

The hardest bug to find was the incorrect loop condition because the program could run without displaying an error message. I knew something was wrong when the answer was not 15, so I checked the loop and realized that the number 5 was being left out. Changing count < 5 to count <= 5 fixed the problem.
